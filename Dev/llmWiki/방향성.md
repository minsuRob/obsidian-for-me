지식이 쌓이는 것과 일이 앞으로 진행되는 것을 연결하는 것

카테고리는 자료가 중복 저장되는 벽

“AI가 제안했다”와 “내가 결정했다”를 구분



- 서버
	- **가져온 결과 정리 보조:** AI가 `llmwiki-result` 형식을 지키지 않고 자유 텍스트로 답했을 때, 그 글을 결과물·결정·할 일·미확인 후보로 나눠 줍니다. 결과는 어차피 "제안"으로 들어가고 확정은 사람이 하니, 지금 앱의 원칙과도 맞습니다.
	- **검토 카드 한 줄 요약과 제목:** run 결과를 1~2줄로 요약합니다. 입력이 1~2천 토큰이면 1~2분 정도라 백그라운드로 돌리면 충분합니다.
	- **업무·자료 분류와 태깅:** 프로젝트, 종류, 우선순위 후보를 붙입니다. 가장 잘한 작업입니다.
		- 공통 지시문을 캐시해 두면 건당 약 4초, 캐시가 없으면 15~20초입니다.
	- 1. **자료 발췌를 미리 만들어 두기:** 긴 문서를 맥락 묶음용 요약으로 밤사이에 미리 만들어 저장해 둡니다. `prepareRun` 때는 저장된 요약을 붙이기만 하면 됩니다.
	1. **오늘 탭 다이제스트:** 어제의 run 상태와 미확인 사항을 하루에 한 번 정리합니다.
	2. **맥락 버전 간 변경 설명:** 짧은 변경 내역을 "무엇이 바뀌었나" 한 줄로 풀어 줍니다.
