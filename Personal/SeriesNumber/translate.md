# 동영상 자막 번역 작업 가이드

## 일반적인 작업 과정

작업 흐름: 원본 동영상 → M4A 음성 추출 → 원어 전사 및 시간코드 생성 → 한국어 번역 → 장면별 검수 및 싱크 조정 → 한글 SRT 저장 → 영상과 함께 재생 확인.

음성을 원어 텍스트로 옮기는 단계는 **전사**, 원어 텍스트를 한국어로 옮기는 단계는 **번역**이다. 두 단계를 구분해 원어 인식 오류와 번역 오류를 각각 확인한다.

### 1. 원본 동영상 확인

- 영상의 언어, 전체 길이, 오디오 트랙과 기존 자막 유무를 확인한다.
- 사용할 음성 트랙을 선택한다. 기존 원어 SRT가 있으면 전사 대신 활용할 수 있지만 영상과 싱크가 맞는지 확인한다.
- 원본 영상과 원어 자막을 보존하고, 추출 음성·전사 자막·한글 자막을 별도 파일로 관리한다.

### 2. M4A 음성 추출

FFmpeg로 영상의 첫 번째 오디오 트랙을 AAC 음성으로 변환해 M4A에 저장한다. 파일명과 경로는 실제 작업 대상에 맞게 바꾼다.

```bash
ffmpeg -n -i "movie.mp4" -map 0:a:0 -vn -c:a aac -b:a 128k "movie.m4a"
```

`-n`은 기존 출력 파일의 덮어쓰기를 막는다. 여러 언어 트랙이 있으면 `-map 0:a:0`을 원하는 트랙에 맞게 변경한다. 이미 M4A에 담을 수 있는 AAC 음성이면 `-c:a aac -b:a 128k` 대신 `-c:a copy`로 재인코딩 없이 추출할 수 있다.

추출 후 처음·중간·끝부분을 들어 누락이나 시간 차이가 없는지 확인한다. 영상 앞부분을 자르거나 오디오 시작 시간이 다른 경우 자막에 적용할 시간 오프셋을 기록한다.

### 3. 원어 전사와 시간코드 생성

- 음성 인식 도구에 실제 원어를 지정하고, 시작·종료 시간이 포함된 원어 SRT를 생성한다. 일본어 영상이라면 `movie.ja.srt`처럼 저장한다.
- 긴 음성을 나눠 처리한다면 각 조각의 원본 시작 시간을 기록하고, 합칠 때 시간코드를 원본 영상 기준으로 환산한다.
- 인물 이름, 호칭, 전문 용어와 음성 인식 오류를 확인한다. 무음에 생성된 문장이나 비정상적으로 반복되는 문장은 실제 음성과 대조한다.
- 알아듣지 못한 대사를 문맥만으로 만들어 넣지 않는다. 불확실한 구간은 따로 기록해 재청취한다.

### 4. 한국어 번역

- 화자 관계와 장면을 먼저 파악하고 원어 자막을 한국어로 번역한다.
- 최소한 앞뒤 5~10개 자막을 함께 보며 생략된 주어, 호칭, 존댓말과 반말을 결정한다.
- 자동 번역 결과는 초벌로 활용하고, 원문 및 실제 음성과 대조해 의미와 말투를 다듬는다.
- 같은 원어라도 화자와 상황에 따라 의미가 달라질 수 있으므로 반복 문장을 일괄 치환한 뒤 반드시 문맥을 검수한다.

### 5. 장면별 검수와 싱크 조정

- 실제 영화나 드라마 자막처럼 발화 시작에 맞춰 표시하고, 발화 종료와 읽는 시간을 고려해 자막을 닫는다.
- 긴 대사는 의미 단위로 나누고, 너무 짧게 표시되는 자막은 인접 대사와의 관계를 확인해 길이나 시간을 조정한다.
- 대사가 끝난 뒤 자막이 과도하게 남거나, 다음 화자의 대사와 겹치거나, 장면 전환을 넘어가는지 확인한다.
- 원어 SRT의 시간을 초깃값으로 쓰되, 실제 발화와 다르면 한글 자막의 시작·종료 시간을 조정한다. 번호와 SRT 문법은 정상적으로 유지한다.
- 영상 처음·중간·끝과 화자가 바뀌는 구간을 재생해 고정된 시간 차이와 뒤로 갈수록 커지는 싱크 오차를 확인한다.

### 6. 최종 저장과 재생 확인

- 한글 자막은 UTF-8 인코딩의 `movie.ko.srt`로 저장한다.
- 영상과 자막을 같은 폴더에 두고 플레이어에서 불러온다. 자동 인식이 안 되면 자막 파일을 직접 선택한다.
- 한글 깨짐, 자막 누락, 줄바꿈, 표시 시간과 싱크를 확인한 뒤 최종본으로 확정한다.

## 번역 유의사항

- 번역된 동영상은 실제 영화나 드라마를 보듯 자연스럽게 느껴져야 한다. 대사가 시작하고 끝나는 시간대를 장면과 발화 흐름에 맞게 구성한다.
- 화자 관계를 먼저 파악한다. 일본어는 주어가 자주 생략되므로 화자와 인물 간의 관계를 확인한 뒤 번역한다.
- 화자 관계와 상황에 맞춰 존댓말과 반말을 구분한다.
- 문장을 단어 단위로 직역하기보다 장면과 상황에 맞는 자연스러운 표현을 우선한다.
- 짧은 감탄사와 추임새는 글자 그대로 옮기기보다 장면의 감정과 말투를 살려 처리한다.
- 성인 표현은 원문의 수위와 어감을 파악하고, 과도하게 순화하거나 불필요하게 거칠게 만들지 않는다.
- 자막의 글자 수와 표시 시간을 고려해 시청자가 읽을 수 있는 길이로 조정한다.
- 호칭과 이름은 전체 자막에서 일관되게 유지한다.
- 장면 단위로 검수한다. 자막 하나만 보고 번역하면 의미가 틀릴 수 있으므로 최소한 앞뒤 5~10개 자막을 함께 확인하고, 가능하면 실제 영상과 대조한다.

## 심화 과정: 갤럭시와 Wi-Fi로 무선 작업

갤럭시가 연결되어 있으면 휴대폰의 원본 영상을 PC로 가져와 위 과정을 진행하고, 완성한 한글 자막을 휴대폰으로 전송해 재생 확인까지 할 수 있다. scrcpy는 휴대폰 화면 확인·조작에, ADB는 파일 전송에 사용한다.

### 1. 연결 상태 확인

PC에 `adb`와 `scrcpy`를 준비하고, 갤럭시와 PC를 같은 로컬 네트워크에 연결한다.

```bash
adb devices -l
```

이미 `IP:포트`가 `device` 상태로 표시되면 해당 연결을 사용한다. `unauthorized`이면 휴대폰에서 디버깅 허용 창을 확인한다. 여러 기기가 있으면 이후 명령에 `-s "기기ID"`를 지정한다.

### 2. Wi-Fi 무선 연결

Android 11 이상에서는 갤럭시의 개발자 옵션에서 **무선 디버깅 → 페어링 코드로 기기 페어링**을 열고, 표시된 주소로 페어링한다.

```bash
adb pair "PHONE_IP:PAIR_PORT"
adb connect "PHONE_IP:CONNECT_PORT"
adb devices -l
scrcpy -s "PHONE_IP:CONNECT_PORT"
```

`PHONE_IP`, `PAIR_PORT`, `CONNECT_PORT`는 실제 화면에 표시된 값으로 바꾼다. 페어링 코드는 요청 시 입력한다. 페어링용 포트와 연결용 포트는 다를 수 있으며, 연결용 주소는 무선 디버깅 기본 화면에서 확인한다.

USB 디버깅으로 먼저 연결한 경우에는 휴대폰에서 연결을 허용한 뒤 다음 명령으로 Wi-Fi 연결을 구성할 수도 있다.

```bash
scrcpy --tcpip
```

무선 연결이 확인되면 USB 케이블을 분리한다. 재연결 시 IP나 포트가 바뀔 수 있으므로 현재 주소와 `adb devices -l` 결과를 확인한다.

### 3. 휴대폰 원본 영상 가져오기

scrcpy에서 **내 파일 → 내장 저장공간 → Download → Netfile**을 열어 대상 영상을 확인한다. 실제 폴더와 파일명을 확인한 뒤 ADB로 PC에 복사한다.

```bash
adb -s "PHONE_IP:CONNECT_PORT" shell ls -l /sdcard/Download/Netfile
adb -s "PHONE_IP:CONNECT_PORT" pull "/sdcard/Download/Netfile/movie.mp4" "./movie.mp4"
```

PC로 가져온 원본에서 M4A 추출 → 원어 전사 → 한국어 번역 → 시간 조정 및 검수를 진행한다. 원본 영상이 이미 PC에 있으면 가져오기 단계는 생략한다.

### 4. 완성된 한글 자막 전송

대상 폴더와 같은 이름의 기존 자막 유무를 확인한다. `adb push`는 같은 경로의 파일을 덮어쓸 수 있으므로 기존 파일이 있으면 새 이름으로 저장하거나 교체 여부를 결정한다.

```bash
adb -s "PHONE_IP:CONNECT_PORT" push "./movie.ko.srt" "/sdcard/Download/Netfile/movie.ko.srt"
adb -s "PHONE_IP:CONNECT_PORT" shell ls -l /sdcard/Download/Netfile/movie.ko.srt
```

여기서 전송은 휴대폰 내부 저장공간에 복사하는 작업이다. Netfile 서비스 자체의 서버에 업로드하는 작업은 별도다.

### 5. 갤럭시에서 최종 확인

- scrcpy에서 파일 목록을 새로고침하고 전송한 자막을 확인한다.
- 휴대폰 플레이어로 원본 영상을 열고 한글 자막을 선택한다. 플레이어가 `.ko.srt`를 자동 인식하지 않으면 직접 불러온다.
- 영상 처음·중간·끝을 재생해 한글 표시와 싱크를 확인한다. 미러링 화면·소리는 지연될 수 있으므로 최종 싱크는 휴대폰 자체 재생으로도 확인한다.
- 수정이 필요하면 PC에서 자막을 보정하고 다시 전송해 확인한다.
- 작업이 끝나면 `adb disconnect "PHONE_IP:CONNECT_PORT"`로 연결을 종료하고, 필요하면 휴대폰의 무선 디버깅도 끈다.
