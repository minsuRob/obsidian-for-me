# 자막 번역 가이드

**자연스러운 한국어 번역을 최우선으로 한다.** 장면과 화자의 의도를 살리고, 의미 없는 발성과 잘못 반복된 인식 결과는 자막에서 제외한다.

원본 확인 → 음성 추출 → 원어 전사 → 한국어 번역 → 싱크 검수 → SRT 저장 → 필요시 폴드 전송 순서로 진행한다. 전사와 번역은 별도로 검토한다.

- [번역과 화자](번역과-화자.md): 말투, 음어, 불필요한 반복, 여성 대사 색상
- [전사와 싱크](전사와-싱크.md): 원본 확인, 음성 추출, 전사, 타이밍과 장면별 검수
- [결과물과 폴드 전송](결과물과-폴드-전송.md): 최종 SRT, ADB·scrcpy, 무선 연결과 전송 확인
