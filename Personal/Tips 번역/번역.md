# 번역: 폴드 영상 → 맥 자막 생성 → 폴드로 전달

갤럭시 폴드5에 있는 대용량 영상(8K, 10GB 이상)에 한국어 자막을 붙이는 절차.
무거운 원본은 폰에서 줄이고, 음성인식과 번역만 맥에서 한다.

```
[폴드] 원본 mp4 ──ffmpeg(오디오만 복사)──▶ m4a
   │                                         │ adb pull (USB)
   │                                         ▼
   │                            [맥] mlx-whisper → ja.srt
   │                                         │ Claude Code 교정·번역
   │                                         ▼
   └──────────── adb push ◀────────── ja.srt / ko.srt
```

자막 생성 자체의 세부 옵션과 교정 요령은 [[자막번역]] 참고.

## 실측 기준 (2026-10-15)

| 단계 | 대상 | 시간 |
|---|---|---|
| 폰에서 오디오 추출 | 15.86GB 8K mp4 → 156MB m4a (84분) | **36초** |
| 맥으로 전송 | adb pull, USB | **4초** (약 40MB/s) |
| 맥 음성인식 | 84분 오디오, large-v3-turbo | **약 5분** |
| 폰으로 되돌려 보내기 | 수십 KB짜리 SRT | 즉시 |

> 폰에서 음성인식까지 하는 건 비추천.
> - Snapdragon 8 Gen 2 CPU로 1.5~3시간이 걸릴 것으로 추정되고, 발열과 배터리 소모도 크다.
> - 번역은 어차피 맥(Claude)에서 해야 한다.

## 0. 최초 준비 (1회)

### 폴드

1. **USB 디버깅 켜기**
   - **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 탭**해서 개발자 옵션을 연다.
   - 개발자 옵션에서 **USB 디버깅**을 켠다.
2. **Termux 설치** (Play 스토어 최신 빌드나 F-Droid)
   - adb로 APK를 넣으면 **자동 차단(Auto Blocker)**이 설치를 막는다 (`INSTALL_FAILED_VERIFICATION_FAILURE`). 그래서 폰에서 스토어로 직접 설치한다.
3. **Termux에서 ffmpeg 설치와 저장소 연결**

   ```bash
   pkg install -y ffmpeg
   termux-setup-storage
   ```

   - "모든 파일 접근" 허용 화면이 뜨면 Termux를 허용한다.
   - `~/storage/downloads`가 폰의 `내장 저장공간/Download`에 연결된다.

### 맥

```bash
brew install android-platform-tools scrcpy
```

```bash
brew install python@3.12
```

```bash
python3.12 -m venv ~/.venvs/whisper && ~/.venvs/whisper/bin/pip install mlx-whisper
```

- brew 기본 `python3`는 3.14라서 `python3.12`가 따로 없다. `python@3.12`를 먼저 설치한다.

- USB 3 데이터 케이블로 폰을 연결하고, 폰에 뜨는 USB 디버깅 허용 창을 승인한다.
- `adb devices`로 연결을 확인한다.
- `scrcpy`를 켜면 폰 화면을 맥에서 보고 조작할 수 있다.

## 1. [폴드] 원본에서 오디오만 추출

Termux에서 실행한다. 재인코딩 없이 오디오 트랙만 복사하기 때문에 10GB가 넘어도 수십 초면 끝난다.

**와일드카드를 ffmpeg에 바로 넘기지 않는다.** `ffmpeg -i *SAVR-1124*.mp4 …`처럼 쓰면 파일이 두 개 걸렸을 때 두 번째 원본 mp4가 *출력 파일*로 해석된다. `-y`가 붙어 있으면 원본이 덮어써진다.

대신 파일을 하나씩 처리하는 스크립트를 쓴다. 맥의 `~/work/sub/extract_audio.sh`를 폰에 넣어 두고 실행한다.

```bash
adb push ~/work/sub/extract_audio.sh /sdcard/Download/extract_audio.sh
```

```bash
bash ~/storage/downloads/extract_audio.sh            # Netfile/ 최상위 mp4 전부
bash ~/storage/downloads/extract_audio.sh IPVR-376   # 이름에 IPVR-376이 들어간 것만
```

- 출력은 항상 `Netfile/srt/<원본과 같은 이름>.m4a` 하나다. 원본 mp4는 출력 대상이 될 수 없다.
- 이미 만든 m4a는 건너뛴다. 중간에 끊겨도 다시 실행하면 이어서 한다.
- 오디오 복사가 안 되면(AAC가 아닌 코덱) AAC 128k로 다시 인코딩한다. 오디오 트랙이 여러 개면 첫 번째(`-map 0:a:0`)만 쓴다.
- 결과는 `Netfile/srt/_extract.log`에 `OK`, `AAC`, `SKIP`, `FAIL`로 남고, 끝나면 `DONE`이 찍힌다.
- 실행 중에는 `termux-wake-lock`으로 폰이 잠들지 않게 한다.

### 맥에서 원격으로 입력할 때 (scrcpy와 adb)

```bash
adb shell am start -n com.termux/.app.TermuxActivity
adb shell "input text 'bash%s~/storage/downloads/extract_audio.sh'" && adb shell input keyevent 66
```

- **Termux를 반드시 맨 앞에 띄운 뒤** 입력한다. 다른 앱이 앞에 있으면 그 앱에 글자가 입력된다.
- 공백은 `%s`로 쓴다. 한글은 `input text`로 입력할 수 없다.
- 전체를 작은따옴표로 감싸야 `*`나 `~`가 폰 쪽 쉘에서 먼저 해석되지 않는다.
- `;`, `|`, `&&`도 폰 쪽 쉘이 먼저 가로챈다. **명령은 한 줄에 하나씩** 보낸다.
- 화면 확인: `adb shell screencap -p /sdcard/Download/_cap.png`를 실행하고 `adb pull`로 받는다.

## 2. [폴드 → 맥] m4a 받기

```bash
mkdir -p ~/work/sub && cd ~/work/sub
adb pull /sdcard/Download/Netfile/srt/영상.m4a .
```

## 3. [맥] 일본어 SRT 생성

```bash
~/.venvs/whisper/bin/mlx_whisper 영상.m4a \
  --model mlx-community/whisper-large-v3-turbo --language ja \
  --output-format srt --output-name ja \
  --condition-on-previous-text False --word-timestamps True \
  --hallucination-silence-threshold 2
```

- m4a를 그대로 넣으면 된다. wav로 바꿀 필요가 없다.

## 4. [맥 → 폴드] 자막 되돌려 보내기

영상과 **같은 폴더에, 같은 이름으로** 넣어야 플레이어가 자막을 자동으로 불러온다.

```bash
adb push 영상.ko.srt "/sdcard/Download/Netfile/<원본과 같은 이름>.srt"
adb push ja.srt "/sdcard/Download/Netfile/<원본과 같은 이름>.ja.srt"
```

- 작업 파일(m4a, 원본 SRT)은 `Netfile/srt/`에 보관한다.
- 폰에서는 **MX Player, VLC, mpv** 등이 같은 이름의 SRT를 자동으로 불러온다. 삼성 기본 비디오 플레이어는 자막 파일을 직접 골라야 할 수 있다.
- 다 끝나면 정리한다: `adb shell rm /sdcard/Download/Netfile/srt/영상.m4a`

## 5. 여러 개를 한 번에 처리하기

폴더 안의 영상을 전부 처리할 때는 1~4단계를 스크립트 두 개로 돌린다.

1. 폰 Termux에서 `extract_audio.sh`를 인자 없이 실행한다. `Netfile/` 최상위 mp4를 전부 m4a로 뽑는다.
2. 맥에서 `run_pipeline.sh`를 실행한다.

```bash
cd ~/work/sub && ./run_pipeline.sh > pipeline.log 2>&1
```

- 폰의 `_extract.log`를 30초마다 읽는다. `OK`나 `AAC`로 끝난 파일부터 받아서 음성인식한다. 추출이 다 끝날 때까지 기다리지 않는다.
- 결과는 영상 옆에 `<영상 이름>.ja.srt`로 넣는다. `<영상 이름>.srt` 자리는 한국어 자막용으로 비워 둔다.
- 처리한 파일은 `~/work/sub/done.txt`에 기록된다. 중간에 끊겨도 다시 실행하면 이어서 한다.
- 맥의 `~/work/sub/srt/`에도 SRT 사본이 남는다.
- 2026-10-15에 17개(합계 약 200GB)로 처음 돌렸다. 폰 추출은 파일당 약 1분 걸렸다.

## 부록: extract_audio.sh

맥에 `~/work/sub/extract_audio.sh`로 저장해 두고 1단계에서 폰에 넣는다.

```bash
#!/data/data/com.termux/files/usr/bin/bash
# Netfile/ 최상위 mp4마다 오디오만 뽑아 Netfile/srt/<같은 이름>.m4a 로 저장한다.
# 파일 하나씩 ffmpeg에 넘기므로 와일드카드가 여러 파일에 걸려 원본을 덮어쓸 일이 없다.
# 사용: bash ~/storage/downloads/extract_audio.sh [파일명 일부(선택)]
DIR=~/storage/downloads/Netfile
OUT="$DIR/srt"
LOG="$OUT/_extract.log"
mkdir -p "$OUT"
termux-wake-lock 2>/dev/null
: > "$LOG"
for f in "$DIR"/*.mp4; do
  [ -f "$f" ] || continue
  name=$(basename "$f" .mp4)
  [ -n "$1" ] && [[ "$name" != *"$1"* ]] && continue
  m4a="$OUT/$name.m4a"
  if [ -s "$m4a" ]; then echo "SKIP $name" >> "$LOG"; continue; fi
  # 출력은 항상 srt/ 안의 .m4a 한 개 → 원본 mp4를 건드리지 않는다
  if ffmpeg -nostdin -hide_banner -loglevel error -y -i "$f" -map 0:a:0 -vn -c:a copy "$m4a"; then
    echo "OK   $name" >> "$LOG"
  elif ffmpeg -nostdin -hide_banner -loglevel error -y -i "$f" -map 0:a:0 -vn -c:a aac -b:a 128k "$m4a"; then
    echo "AAC  $name" >> "$LOG"
  else
    rm -f "$m4a"; echo "FAIL $name" >> "$LOG"
  fi
done
echo DONE >> "$LOG"
termux-wake-unlock 2>/dev/null
```

## 부록: run_pipeline.sh

맥에 `~/work/sub/run_pipeline.sh`로 저장해 두고 5단계에서 실행한다.

```bash
#!/bin/zsh
# 폰 Netfile/srt/*.m4a → 맥 mlx-whisper(ja) → 폰 Netfile/<같은 이름>.ja.srt
setopt null_glob
cd ~/work/sub
PH=/sdcard/Download/Netfile
W=~/.venvs/whisper/bin/mlx_whisper
done_list=done.txt; touch $done_list
while true; do
  log=$(adb shell cat "$PH/srt/_extract.log" 2>/dev/null)
  # OK/AAC 로 끝난 것만 처리
  echo "$log" | grep -E '^(OK|AAC) ' | sed -E 's/^(OK|AAC) +//' | while IFS= read -r name; do
    grep -Fxq "$name" $done_list && continue
    echo "[$(date +%T)] pull $name"
    adb pull "$PH/srt/$name.m4a" "in.m4a" >/dev/null </dev/null || continue
    echo "[$(date +%T)] whisper $name"
    $W in.m4a --model mlx-community/whisper-large-v3-turbo --language ja \
      --output-format srt --output-name ja --output-dir out \
      --condition-on-previous-text False --word-timestamps True \
      --hallucination-silence-threshold 2 --verbose False </dev/null || { echo "WHISPER FAIL $name"; continue; }
    mkdir -p srt; cp out/ja.srt "srt/$name.ja.srt"
    adb push "srt/$name.ja.srt" "$PH/$name.ja.srt" >/dev/null </dev/null && echo "$name" >> $done_list
    echo "[$(date +%T)] pushed $name"
  done
  echo "$log" | grep -q '^DONE' && \
    [ $(echo "$log" | grep -cE '^(OK|AAC) ') -le $(wc -l < $done_list) ] && { echo ALL DONE; break; }
  sleep 30
done
```
