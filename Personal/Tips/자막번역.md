# 자막번역: 일본어 영상 → 일본어 SRT + 한국어 SRT

맥(Apple Silicon)에서 무료 도구만으로 영상 음성을 일본어 자막으로 뽑고, Claude Code로 한국어 자막을 만드는 절차.
2026-10-15, 「천년혈전 1화」(26분)로 처음 해 봄.

## 구성

| 단계 | 도구 | 비고 |
|---|---|---|
| 오디오 추출 | ffmpeg | brew로 설치되어 있음 |
| 일본어 음성인식 | **mlx-whisper** + `whisper-large-v3-turbo` | Apple Silicon GPU 사용, 맥에서 가장 빠름 |
| 교정·번역 | **Claude Code** | SRT를 직접 읽고 교정·번역 (추가 비용 없음) |
| 재생 | **IINA** | QuickTime은 외부 SRT를 못 읽음 |

> Claude는 음성 파일을 직접 못 받는다. 그래서 음성인식은 로컬에서, 번역만 Claude가 한다.

## 1. 설치 (최초 1회)

```bash
python3.12 -m venv ~/.venvs/whisper
~/.venvs/whisper/bin/pip install mlx-whisper
brew install --cask iina
```

- 시스템 `/usr/bin/python3`(3.9)가 아니라 brew의 `python3.12`로 venv를 만든다.
- 모델(약 1.6GB)은 처음 실행할 때 Hugging Face에서 받는다. 이번에는 약 4분 걸림.

## 2. 오디오 추출

```bash
ffmpeg -i "영상.mp4" -vn -ac 1 -ar 16000 audio.wav
```

## 3. 일본어 음성인식 → SRT

```bash
~/.venvs/whisper/bin/mlx_whisper audio.wav \
  --model mlx-community/whisper-large-v3-turbo \
  --language ja \
  --output-format srt --output-name ja \
  --condition-on-previous-text False \
  --word-timestamps True \
  --hallucination-silence-threshold 2
```

- 26분 영상 기준 음성인식 자체는 **약 1분 20초** (M5, 16GB).
- `--language ja`를 꼭 고정한다. 자동 감지는 BGM 구간에서 틀어진다.
- 아래 두 옵션은 Whisper의 무음 환각과 반복 출력을 줄인다.
  - `--condition-on-previous-text False`
  - `--hallucination-silence-threshold 2`

## 4. 교정 (Claude Code)

Whisper 원본을 그대로 쓰면 안 된다. 다음을 정리한다.

- **고유명사 오인식**: 작품 용어가 비슷한 발음의 일반 단어로 바뀐다.
  - 예) 卍解→挽回, 一護→一郎, 空座町→カラクラ帳, 虚(ホロウ)→フォロー
  - 작품명을 알려 주면 Claude가 문맥으로 꽤 잘 복원한다.
- **삭제할 구간**:
  - 방송 광고와 스폰서 멘트
  - 무음 환각 (「ご視聴ありがとうございました」, `me` 반복 등)
  - 효과음 (ガシャン 등)
  - OP·ED 가사
- **분리 대사**: 두 사람이 한 cue에 섞이면 `- 대사1\n- 대사2` 형식으로 나눈다.

## 5. 한국어 번역 (Claude Code)

요청 예시:

> `ja.srt`를 교정하고, 타임코드는 유지한 채 자연스러운 한국어 구어체로 번역해서 `영상이름.ko.srt`로 저장해 줘. 캐릭터 말투(반말/존댓말)를 일관되게 유지하고, 한 줄이 22자를 넘으면 두 줄로 나눠 줘.

- Claude는 cue 번호별로 `(일본어 교정본, 한국어)` 매핑 표를 만든다.
- 이 표를 파이썬 스크립트로 SRT에 적용하고 번호를 다시 매긴다.
- 결과: `영상이름.ja.srt`(교정본)와 `영상이름.ko.srt`를 영상 옆에 저장한다.
- 이번 결과: 원본 cue 319개 → 광고·환각·가사를 빼고 262개.
- 마지막으로 SRT가 깨지지 않았는지 확인한다.

```bash
ffmpeg -v error -i "영상이름.ko.srt" -f srt -y /dev/null
```

### 주의

- 음성이 뭉개진 구간(무전, 기계음, 숫자 나열)은 인식 결과도 번역도 추정이다. 영상을 보면서 확인할 것.
- 용어는 국내 정발 표기를 따르는 게 좋다. 블리치 예: 사신 대행, 호로, 아란칼, 만해, 루콘가이, 호정 13대.

## 6. 재생

- **IINA**: 영상과 파일 이름이 같으면(`영상이름.ko.srt`) 자막을 자동으로 불러온다.
  - 이중 자막: **자막 → 보조 자막**에서 `ja.srt`를 고른다.
  - 터미널에서 열기: `iina "영상.mp4"`
- **QuickTime으로 보고 싶으면** 자막을 mp4 안에 넣는다. 재인코딩이 없어서 몇 초면 끝난다.

```bash
ffmpeg -i "영상.mp4" -i "영상.ko.srt" -c copy -c:s mov_text -metadata:s:s:0 language=kor "영상.자막.mp4"
```

## 다른 선택지 (참고)

- **whisper.cpp** (`brew install whisper-cpp`): 파이썬 없이 쓰는 CLI. Metal 가속을 쓴다.
- **kotoba-whisper v2**: 일본어 특화 Whisper 모델. 노이즈나 구어체에 강하다.
- **yt-dlp**: 유튜브 영상이면 일본어 자동자막을 먼저 받아 보고, 쓸 만하면 음성인식을 건너뛴다.
- faster-whisper, WhisperX: 맥에서는 CPU로만 돌아서 느리다. WhisperX는 화자 분리가 필요할 때만 쓴다.
