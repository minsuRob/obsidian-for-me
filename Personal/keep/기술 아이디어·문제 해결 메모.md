# 기술 아이디어·문제 해결 메모

## 터미널 세션 UX 아이디어 — 2026-07-06

코딩 작업이 멈추거나 끝났을 때 세션 창 테두리를 잠깐 강조하고, 세션 안 드래그 선택을 자동 복사로 연결하며, 입력창에서 오른쪽 클릭을 지원하자는 아이디어를 적었다. Mymux와 Cmux·Conductor·Superset 비교 링크도 같은 날 저장했지만, 이 아이디어가 특정 제품에 구현됐다는 뜻은 아니다. 현재 제품 상태나 우선순위는 확인되지 않았다.

## 집 인터넷 업로드 손상 관찰 — 2026-08-14~22

당시 메모에는 일정 크기 이상의 업로드에서 데이터 무결성 오류가 반복되고 다운로드는 정상인 증상이 기록되어 있다. 같은 장치의 핫스팟·다른 회선·집 안 LAN 전송을 대조해 WAN 경로에서만 재현되는 것으로 범위를 좁혔다. 공유기 재시작은 개선되지 않았다고 기록했다.

- **관찰과 해석 구분:** 대조 결과는 집의 WAN 경로 문제를 시사하지만, 당시 메모의 장비·액세스망 원인 설명은 가설이다. 특정 장비 결함이나 ISP 원인이 최종 확인·해결됐다는 후속 기록은 이 자료에서 찾을 수 없다.
- **개인정보 최소화:** 내부 주소, 장비 식별값, 계정 정보, 상세 측정 자료와 상담 대응 문구는 이 요약에 옮기지 않았다.
- **현재성:** 2026년 8월의 과거 장애 기록이므로 현재도 재현되는지 알 수 없다.

## 앱 심사 준비 메모 — 2026-10-02

Markhub 앱의 당시 메모는 홈 화면 위젯에 허브 목록과 미팅 진입 동작을 설명하고, 심사 계정에 표시할 데이터를 준비하며, 위젯 버튼이 앱을 연 뒤 미팅 화면으로 이어지는 흐름을 확인하자는 내용이다. 앱이 열리자마자 녹음을 시작한다면 녹음 중임을 화면에서 명확히 보여야 한다는 검토 항목도 있었다.

이는 당시 전달·작성된 심사 준비 메모다. 구현 완료 여부, 현재 화면 동작, 현행 App Review 지침의 의미를 확정하지 않는다. 자세한 분리는 업무 Wiki의 [[홈 화면 위젯과 미팅 진입 심사 메모]]에 두었다.
