팀소개
New Media 팀은 브랜딩과 기술의 경계를 탐구하며 새로운 형태의 경험과 인터페이스를 실험하는 조직입니다.
AI, 인터랙티브 미디어, 공간 경험, 그리고 디지털 제품을 통해 기존의 방식과 다른 브랜드 경험을 만들어갑니다.
현재 우리는 새로운 모바일 앱 경험을 개발하고 있으며, 이 프로젝트를 함께 만들어갈 UI Designer를 찾고 있습니다.
Mission
우리는 AI 기술을 이용한 완전히 새로운 형태의 사용자 인터페이스를 만들고 있습니다.
이 프로젝트는 기존의 앱 UI를 반복하는 것이 아니라, AI와 새로운 인터페이스 경험을 구현하는 작업입니다.
이 포지션은 제품의 UX 구조를 기반으로 실제 사용자 인터페이스와 인터랙션 경험을 디자인하는 역할입니다.
단순히 화면을 정리하는 것이 아니라, 제품의 시각 언어와 인터페이스 경험을 만들어가는 역할을 담당합니다.
Product UI Designer는 UX Strategist와 협업하며 아이디어와 구조를 실제 사용자 경험으로 구현하고,
디자인, 시스템, 인터랙션, 화면 디테일을 통해 제품의 완성도를 만들어갑니다.
UX Strategist는 디자이너, 엔지니어와 협업하며 제품의 큰 그림과 경험의 논리를 만들어가는 역할을 담당합니다.
담당업무
Problems you’ll work on
• 새로운 UI 스타일을 탐구합니다.
• AI 인터페이스의 시각적 표현을 설계합니다.
• 인터랙션 디자인을 설계합니다.
• 모바일 앱 경험의 디테일을 설계합니다.
What you’ll actually do
• 모바일 앱 UI 디자인을 설계합니다.
• 인터랙션 디자인을 설계합니다.
• 디자인 시스템을 구축합니다.
• 프로토타입을 제작합니다.
• UX 전략을 실제 UI로 구현합니다.
