Narnia Labs (나니아랩스)
나니아랩스는 모든 사람이 최고의 제품을 설계할 수 있는 세상을 만들어 가는 AI 기업입니다.
우리는 빅테크 AI 기업이 할 수 없는 제조업의 설계 도메인에 특화된 버티컬 AI 솔루션을 제공합니다.
나니아랩스의 AI 솔루션을 통해 고객은 더 좋은 제품을 더 빠르게 설계할 수 있게 되고, 제품 경쟁력을 높일 수 있습니다.
[이런 일을 함께 고민해요]
제조 현장 친화적인 Desktop 경험 구축
: 보안·오프라인·대용량 데이터를 다뤄야 하는 현장 요구에 맞는 클라이언트 경험을 설계합니다.
설계 도메인 에이전트 프로덕션화
: 제안 → 평가 → 비교 → 피드백 반영의 Agentic 루프를 실제 제품 흐름에 녹여냅니다.
대용량 공학 데이터 처리
: 설계·시뮬레이션 데이터에 적합한 파이프라인과 인터페이스를 설계합니다.
AI Native 기업을 지향하는 만큼, 우리는
BE/FE/ML/Data의 역할 경계를 고정된 선이 아니라 제품이 필요로 하는 만큼 유연하게 움직이는 선
으로 봅니다. 주력 영역은 있되, 제품에 필요하면 영역을 넘어 직접 익혀 해결하는 방식이 우리와 잘 맞습니다.
나니아랩스의
AI Product Engineer는 설계자의 문제를 1인칭으로 끌어안고, 풀스택으로 End-to-End 제품을 책임지는 메이커
입니다. 제품에 필요하면 영역을 가리지 않고 직접 손을 대고, 모르는 영역은 학습으로 들어갑니다.

제품의 E2E 오너십
: 가설 → 프로토타입 → 프로덕션까지 기능을 직접 설계·구현·배포합니다.
Desktop 전환
: 제조 현장에 맞는 클라이언트 경험을 함께 만들어갑니다.
Agentic 워크플로우 개발
: AI가 설계 과정에 자연스럽게 녹아드는 경험을 제품에 구현합니다.
AI를 기본 작업도구로 활용
: 에이전트 기반 개발을 전제로, 본인과 팀의 생산성을 배수로 끌어올립니다.
비즈니스 임팩트로 결과 정의
: 기능 완성이 아니라 설계자의 실제 사용·채택까지의 결과를 성과로 봅니다.
