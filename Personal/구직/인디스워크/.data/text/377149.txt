About the Team & Mission
42dot의 Navigation Agent 팀은 사용자의 의도와 이동 맥락을 이해하고, 복잡한 내비게이션 기능을 자연스럽게 수행할 수 있는 AI Agent를 개발합니다.
우리는 LLM을 기반으로 사용자의 요청을 해석하고 적절한 기능과 데이터를 활용해 답변과 행동을 생성하는 모델을 만들고 있습니다. 동시에 내비게이션에서 축적되는 다양한 데이터에 머신러닝 기술을 적용하여 Agent의 판단 정확도와 사용자 경험을 지속적으로 개선합니다.
LLM Fine-tuning부터 전통적인 Machine Learning 모델 개발, 데이터 구축, 평가 및 서비스 적용까지 Agent 모델 개발의 전 과정을 함께할 AI Engineer를 찾습니다.
Responsibilities
Navigation Agent를 위한 LLM Fine-tuning 및 Post-training 수행 (Instruction Tuning, Supervised Fine-Tuning, Preference Optimization 등 목적에 적합한 학습 방법 설계 및 적용)
사용자 발화와 이동 맥락을 이해하고 적절한 내비게이션 기능을 수행하는 Agent 모델 개발 (사용자 의도 및 정보 추출, Tool 및 API 선택과 실행 계획 생성, 대화 맥락을 고려한 응답 및 행동 생성)
분류, 예측, 랭킹 등 전통적인 Machine Learning 기법을 활용한 Agent 구성 모델 개발
학습 및 평가 데이터셋 구축과 데이터 품질 개선
Agent의 성능 평가 체계와 핵심 지표를 설계하고, 실패 사례를 분석하여 모델 품질 개선
실제 서비스 환경에서 모델의 정확도, 안정성 및 응답 속도 최적화
Navigation, Backend, Data 및 Product 조직과 협업하여 모델을 제품에 적용하고 지속적으로 개선
