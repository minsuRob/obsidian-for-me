Overview
XCENA는 LLM 추론 성능을 극대화하기 위한 KV Cache 인프라를 개발하고 있습니다.
CXL Memory 기반 KV Cache 엔진의 핵심 아키텍처를 자체 설계·구현하며, XCENA의 CXL Computational Memory Device 위에서 다수의 LLM 인스턴스가 KV Cache를 효율적으로 공유할 수 있는 소프트웨어 스택을 만듭니다.
LLM Serving의 KVCache 병목을 하드웨어-소프트웨어 공동 최적화로 해결하는 데 관심이 있는 System Software Engineer를 찾고 있습니다.
담당 업무
CXL Memory 기반 KV Cache 스토리지 엔진의 핵심 모듈 설계 및 구현
LLM 추론 엔진(vLLM, SGLang 등)과 연동되는 KV Cache 저장·조회·공유 파이프라인 최적화
GPU ↔ CPU ↔ CXL 간 KV Cache 계층적 메모리 관리 및 데이터 이동 최적화
다수의 LLM 인스턴스 간 KV Cache 공유를 위한 메모리 풀링, 동시성 제어, RPC 통신 설계
오픈소스 KV Cache 관리 시스템(LMCache, vLLM 등)의 기능 개발 및 커뮤니티 기여
