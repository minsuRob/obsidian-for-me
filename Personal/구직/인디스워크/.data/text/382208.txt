백엔드 서비스 개발 (3년 이상)
주요업무
• 정비·예약·결제·인증·회원 등 제품 도메인의 기능을 설계하고 구현합니다.
• Kotlin/Java + Spring 기반의 API 서버를 개발하고, 마이크로서비스 간 연동을 설계합니다.
• 정합성이 중요한 도메인의 트랜잭션 경계와 엣지 케이스, 이벤트 소비의 멱등성을 설계합니다.
• 기능 개발과 함께 주변의 오래된 코드를 점진적으로 개선합니다.
• 운영에 필요한 백오피스를 개발하고, 자신이 만든 기능의 장애 대응에 참여합니다.
• 동료의 코드를 리뷰하고 자신의 코드에 대한 리뷰를 받으며 팀의 기준을 함께 만듭니다.
• AI를 활용해 오래된 코드의 맥락을 파악하고 반복 작업을 넘기며, 팀이 일관된 수준으로 AI를 쓸 수 있도록 개발 컨텍스트를 함께 정비합니다.
[기술 스택]
• 언어·프레임워크 : Kotlin/Java, Spring
• 클라우드 : AWS
• 컨테이너·오케스트레이션 : ECS, EKS, k3s, Helm
• 데이터베이스 : Aurora, DynamoDB, Redis, OpenSearch, Athena
• 메시징 : Kafka, SNS/SQS
• IaC·배포 : Terraform, AWS CDK, GitHub Actions, ArgoCD
• 관측·운영 : Datadog, Grafana, CloudWatch
• 협업 관련 : Git, Asana, Slack, Confluence
• 기타 : Python, TypeScript
자격요건
﻿• Kotlin/Java와 Spring Framework로 프로덕션 서비스를 개발·운영한 경험이 3년 이상인 분
﻿• 직접 작성한 코드의 설계 판단과 엣지 케이스를 스스로 설명할 수 있는 분
﻿• RESTful API 또는 GraphQL을 설계하고 개발한 경험이 있는 분
﻿• RDBMS 스키마 설계와 SQL 작성·튜닝에 대한 이해가 있는 분
﻿• 코드리뷰를 주고받으며 개발한 경험이 있고, 피드백을 반영해 더 나은 안을 제시할 수 있는 분
﻿• 요청받은 기능을 그대로 만들기 전에 “왜 필요한가”, “더 나은 방법은 없나” 를 먼저 묻는 분
﻿• AI 코딩 도구를 실무에 쓰고 있고, 어디까지 맡기고 어디부터 직접 검증하는지 본인의 기준을 설명할 수 있는 분
우대사항
﻿• 결제·정산·예약 등 데이터 정합성이 중요한 도메인을 개발·운영한 경험이 있는 분
﻿• 마이크로서비스 아키텍처에서 서비스 간 경계와 분산 트랜잭션을 다뤄본 경험이 있는 분
﻿• 대용량 트래픽 서비스의 성능 문제를 진단·개선한 경험이 있는 분
﻿• 레거시 코드의 리팩터링·테스트 도입을 주도한 경험이 있는 분
﻿• 테스트 자동화나 정적 분석으로 팀의 품질 기준을 코드로 강제해 본 경험이 있는 분
﻿• 팀이 AI를 일관되게 쓸 수 있도록 컨텍스트·규칙·워크플로를 정비해 본 경험이 있는 분
﻿• 마이클 또는 유사한 차량관리·O2O 서비스를 사용해 본 경험이 있는 분
