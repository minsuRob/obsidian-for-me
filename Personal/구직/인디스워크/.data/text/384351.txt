EMR/CRM을 개발하는 클리닉 운영 플랫폼(ClinicOps) 그룹입니다 🚀
한의원 EMR은 단순히 진료 기록 도구가 아닙니다.
원장님은 진료에만 집중하고, 직원들은 환자만 살피도록 다른 모든 업무를 책임 지는 운영체제(OS) 입니다.
클리닉 운영 플랫폼 그룹은 네 개의 제품을 운영합니다.
전자차트(EMR): 진료, 예약, 청구를 아우르는, 한의원 모든 워크플로의 허브입니다.
CRM: 환자의 건강 상태와 진료 성과를 바탕으로 촘촘한 관리 체계를 만듭니다.
홈페이지: 한의원의 브랜드와 콘텐츠를 꼭 맞는 환자에게 전달합니다.
BI: 데이터 기반 경영이 가능하도록 핵심 지표를 한눈에 보여줍니다.
함께 할 동료의 한마디
“여기서는 ‘이거 좀 이상한데요?’ 가 제일 환영받는 말이에요. 이건 네 일, 저건 내 일 하고 선 긋는 사람이 없거든요. 솔직히 시키는 일만 하고 싶은 분께는 피곤한 팀이에요. 대신 사용자를 읽는 감각이 뾰족해집니다. 내 판단이 제품에 빠르게 박히는 걸 보고 싶은 분이라면, 이만큼 빠른 곳도 드물 겁니다.”
– ClinicOps 그룹 백엔드 엔지니어 최수아
“최근 저희 팀이 집중하고 있는 건, 사내의 커뮤니티나 마켓, 브랜드 서비스들을 진료 기록이랑 한의원 운영 데이터가 모이는 전자차트(EMR) 중심으로 통합하는 작업이에요. EMR 뿐만 아니라 다양한 도메인 지식을 습득할 수 있다는 게 매력적이라고 생각합니다. B2B SaaS지만 비교적 가까운 한의원에 고객분들이 있기 때문에 긴밀하게 목소리를 듣을 수 있다는 것도 장점이라고 생각해요. 원한다면 직접 현장을 경험해보고 능동적으로 문제를 정의하고 해결하는 일련의 과정을 경험할 수도 있어요!”
– ClinicOps 그룹 백엔드 엔지니어 허태정
백엔드 엔지니어, 어떤 일을 하나요? 👨🏻‍💻
ClinicOps 코어 파트 백엔드 엔지니어는 한의원의 업무 전체를 다루는 전자차트(EMR)과 고객관리 도구(CRM)을 만듭니다.
업스트림 차트 (EMR)
— 원무·진료·치료실·예약·탕전·청구·전자서명까지, 한의원 운영의 모든 흐름이 업스트림 위에서 끊김 없이 이어지도록 합니다.
업스트림 CRM
— 환자 조건 필터링, 문자·카카오톡 발송 워크플로우, 캠페인 효과 측정. 원장님이 매일 여는 환자 관리 화면입니다.
📚주요 업무
EMR 데이터 마이그레이션 자동화
고객이 사용하던 EMR에서 추출한 환자·예약·진료·수납 데이터를 업스트림 EMR 데이터 구조에 맞게 변환하고 적재합니다.
데이터 형식 차이와 예외 케이스를 분석하고, 누락·중복·정합성 오류를 자동으로 검증합니다.
실제 한의원 데이터 이전에 적용하며, 반복할수록 더 빠르고 정확해지는 마이그레이션 체계를 만듭니다.
EMR 고객 이슈 진단 백오피스
CX가 한의원과 환자를 검색해 예약, 접수, 진료, 수납, 데이터 변경·삭제, 메시지 발송 등 주요 이벤트를 시간순으로 확인할 수 있는 백오피스를 개발합니다.
CX가 고객의 오조작과 시스템 오류를 구분하고, 개발팀에 전달하기 전에 문제 상황을 파악할 수 있도록 진단 정보를 제공합니다.
시스템 문제를 개발팀에 인계할 때 필요한 데이터와 처리 이력을 명확하게 남겨 문제 해결 시간을 단축합니다.
신규 한의원 계정 개통 자동화 백오피스
신규 한의원 개통에 필요한 병원·사용자 정보를 입력하고 검증하는 기능을 개발합니다.
권한, 진료실, 예약, 청구 등 기본 설정을 정해진 기준에 따라 자동으로 구성합니다.
데이터 마이그레이션 진행 상황과 결과를 추적하고, 누락된 설정이나 후처리 작업을 관리합니다.
개통 과정에서 반복되는 수작업과 설정 오류를 줄여 고객이 더 빠르게 서비스를 시작하도록 합니다.

😄 ClinicOps 그룹 코어 파트 백엔드 엔지니어는 이런 경험을 합니다.
이제 막 출시된 서비스와 함께 성장합니다.
잘 정리된 연습용 과제가 아니라 팀 백로그에 있는 진짜 작업을 맡고, 리뷰를 거친 코드는 실제 한의원 화면에 배포됩니다. 오늘 고친 버그가 내일 원장님의 진료 화면에 반영되는 속도감을 경험합니다.
사용자 경험과 맞닿아있는 제품을 만듭니다.
‘좋은 제품’의 대부분은 도메인 모델과 API 설계가 결정합니다. 내가 모델링한 스키마가 유저들의 동선이 되고, 내가 지킨 정합성이 신뢰가 됩니다. 백엔드 엔지니어로서, 유저 경험을 직접 만드는 경험을 쌓을 수 있습니다.

진료 한 번에도 차트 기록, 수납, 보험 청구, 다음 예약이 정확히 맞물려야 합니다. 한의원 운영의 모든 흐름을 다루는 EMR 도메인 아래에는 백엔드 엔지니어가 탐내는 문제들이 다 모여 있습니다 — 예약의 동시성, 결제와 청구의 트랜잭션 정합성, 멀티테넌트 격리, 외부 연동의 멱등성과 재시도. 책과 블로그에서만 보던 문제들을 실제 서비스에서 풀며, 복잡한 현실을 코드로 정리하는 근육을 만듭니다. 이 기본기는 어떤 도메인을 만나도 통합니다.
AI 네이티브 개발 환경을 경험합니다.
전 구성원이 Claude Code와 Codex를 사용합니다. AI 도구는 쓰는 만큼 지원합니다 — Pro 한도가 부족해지면 Max로 올려드립니다. 인턴도 예외가 아닙니다. 스펙은 LLM이 읽을 수 있게 구조화해서 관리하고, 에이전트에게 작업을 위임하는 워크플로우를 함께 발전시킵니다. 도구로 쓰는 것을 넘어
제품 자체에 AI를 녹여내는 과정에, 커리어의 시작점부터 참여
합니다.
