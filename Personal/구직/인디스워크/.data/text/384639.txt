Role Overview
This intern will serve as a technical integrator and protocol enforcer, responsible for ensuring that all intern-developed tools and existing applications are MCP-compliant. Acting as the central point of coordination for cross-project MCP standardization, the intern will design and implement a MCP-Based Intern Project Linkage Framework. This includes building and maintaining a shared MCP server that exposes APIs, datasets, and simulation engines, enabling seamless interoperability across intern projects. The intern will also support other interns in integrating their tools via MCP clients, fostering a unified ecosystem of AI-enhanced engineering workflows.

Python (for MCP server/client development)
REST API
Experience with LLM and MCP
