조직 소개
우리 조직은 데이터가 수집, 저장, 처리, 분석, 서빙되는 전 과정을 담당하는 데이터 전문 조직입니다.
카카오페이 전사의 데이터 인프라와 플랫폼을 구축하고 운영하며, 수천만 사용자의 데이터를 매일 안정적으로 다루고 있습니다.
또한 실시간/배치 데이터 파이프라인, 대용량 데이터 저장소, 고성능 데이터 서빙 API를 담당하며, 카카오페이의 핵심 데이터 흐름을 직접 설계하고 운영합니다.
카카오페이의 모든 서비스가 필요한 데이터를 제때 쓸 수 있도록, 어떤 규모에도 버텨내는 데이터 플랫폼을 만드는 것이 우리의 목표입니다.
우리 조직은 지표와 데이터를 기반으로 기술적 의사결정을 내리고, 아주 작은 기능부터 아키텍처 결정까지 스스로 판단하고 끝까지 책임지는 방식으로 일합니다.
성능 개선과 아키텍처 개선을 구성원 누구나 주도적으로 제안하고 실행할 수 있으며, 최신 데이터 기술을 직접 검토하고 도입하며 기술적 도전을 즐기는 문화를 만들어가고 있습니다.
합류하시면 수천만 사용자의 금융 데이터를 처리하는 데이터 플랫폼 시스템 자체를 개발하고, 고성능 데이터 서빙 API를 직접 설계·구현하는 경험을 할 수 있습니다.

직무 소개
업무내용
카카오페이의 다양한 서비스를 위한 데이터 플랫폼 개발 및 운영을 담당합니다.
데이터 수집부터 저장, 처리, 분석, 서빙까지 전체 데이터 라이프사이클을 관리하는 시스템을 구축합니다.
고성능 데이터 서빙 API를 설계하고 구현하여 다양한 서비스에 데이터를 제공합니다.
서비스 안정성과 성능 개선을 위한 기술적 과제를 주도적으로 발굴하고 해결합니다.
시스템의 문제를 스스로 발견하고 개선 방향을 제안하며, 설계·개발·운영 전 단계에서 기술적 의견을 제시합니다.
필요 역량/경험
컴퓨터공학 또는 관련 전공 학위 (또는 이에 준하는 전공)
1년 이상의 서버 개발 경력
Kotlin, Spring Framework(Spring Boot) 기반 백엔드 개발 능력
고성능 데이터 서빙 API 설계 및 개발 경험
MySQL 등 RDBMS 설계 및 쿼리 튜닝 능력
Redis 등 캐시 활용 경험
대용량 데이터 처리 및 분산 시스템에 대한 이해도
선호 역량/경험
MongoDB 등 NoSQL 데이터베이스 활용 경험
Kafka 등 메시징/스트리밍 시스템 활용 경험
Docker, Kubernetes 환경에서의 서비스 운영 경험
AI 도구(Copilot, Claude 등)를 개발 프로세스에 적극 활용한 생산성 향상 경험
데이터 도메인(데이터 플랫폼, 파이프라인, 분석 서빙 등)에 대한 이해도
자기 주도적으로 업무를 진행하고, 서비스의 개선점을 주도적으로 발굴하는 자세

다양한 직군과 협업했던 경험과 본인의 커뮤니케이션 방식에 대해서도 들려주시면 좋습니다.
