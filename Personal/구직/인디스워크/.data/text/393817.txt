생성 AI(Gen AI)로 기업의 혁신을 켜는(On) 제논
제논은 생성형 AI 기반의 B2B 솔루션을 제공하는 인공지능(AI) 전문 기업입니다.
국내 최초의 AI 전문 컨설팅펌으로 출발한 제논은 비즈니스와 AI, IT에 대한 전문 지식과 다양한 산업 적용 경험을 바탕으로 AI 전략 수립부터 모델 개발, 시스템 구축까지 전 과정을 아우르는 통합 서비스를 제공합니다.
제논의 핵심 경쟁력은 지난 8년 동안 200여개 이상의 다양한 AI 프로젝트를 수행하며 확보한 여러 AI 분야에 기술 역량과 전 산업 영역에 걸쳐진 고객사들의 문제를 해결했던 경험과 노하우에서 기반합니다. 기업 고객이 현장에서 더욱 고도화된 업무 혁신을 실현할 수 있도록 LLM과 생성형 AI에 기반을 둔 인공지능 솔루션올 통해 End-to-End 인공지능 프로페셔널 서비스를 선보이고 있습니다.
제논은 생성형 AI 기술의 연구·개발 역량과 AI 전략 컨설팅 전문성을 바탕으로, 다양한 기업 고객의 니즈에 최적화된 솔루션을 개발하는 데 집중하고 있습니다. 특히 AI 모델 개발부터 데이터 분석, 업무 자동화, 에이전트 설계에 이르기까지 AI 서비스 구현과 적용에 필요한 모든 단계에 걸친 통합형 서비스를 제공하며, 실제 사용자 환경에서 바로 적용 가능한 형태로 높은 완성도의 결과물을 창출합니다.
제논과 함께 기술과 비즈니스의 간극을 좁히며 비즈니스 혁신을 만드는 AI Translator의 커리어를 열어가세요.
■ Agentic AI Engineer
[ 채용직무 소개 ]
OneAgent는 LLM이 사용자를 대신해 브라우저와 컴퓨터를 직접 조작해 실제 업무를 수행하는 데스크톱 AI 에이전트입니다. 웹에서 정보를 찾고, 여러 도구를 넘나들며 작업하고, 결과물을 만들어 내는 과정을 에이전트가 스스로 계획하고 실행합니다.
본 포지션은 OneAgent의 핵심인 에이전트 엔진을 개발하며, LLM의 추론을 신뢰할 수 있는 실제 동작으로 연결하는 아래 영역을 설계·구현합니다.
• Tool Call — LLM이 어떤 도구를 언제, 어떤 인자로 호출할지 결정하는 로직과 실행·에러 복구 파이프라인
• MCP(Model Context Protocol) — 외부 서비스·데이터를 표준 프로토콜로 연결하는 커넥터 통합
• Browser Use — 실제 브라우저(CDP)를 제어해 페이지를 탐색·클릭·입력하는 자동화
• Computer Use — 데스크톱 화면을 인식하고 직접 조작하는 자동화
[ 주요 업무 ]
• LLM 에이전트 실행 루프(추론 도구 선택 실행 관찰 재계획) 설계 및 고도화
• Tool Calling 파이프라인 구축 — 도구 스키마 정의, 호출 신뢰성·재시도·에러 복구
• MCP 커넥터 통합 — 외부 서비스·데이터 소스 연결 및 OAuth 등 인증 처리
• Browser Use / Computer Use 자동화 — 브라우저(CDP)·데스크톱 조작 및 액션 정확도 개선
• 에이전트 동작의 평가(eval) 체계 구축 — 성공률·개입률 측정, 리그레션 방지
• 최신 에이전트·LLM 연구 리뷰 및 사내 기술 공유
• 데스크톱 앱(Electron) 및 백엔드 에이전트 서버 개발·운영
[ 자격 요건 ]
• 컴퓨터공학, 소프트웨어, AI 등 관련 전공 학사 이상
• TypeScript/JavaScript 또는 Python 기반 개발 경험
• 다음 영역 중 하나 이상에 대한 학습·프로젝트·논문·실무 경험 보유
– Tool Calling / MCP 등 LLM 도구 연동
– Browser 자동화 (Playwright, Puppeteer, CDP 등)
– Computer Use / RPA / 웹 스크래핑 등 화면 기반 자동화
• 새로운 기술을 빠르게 학습하고, 실험을 직접 설계·실행해 결론을 도출할 수 있는 능력
• 동료와의 협업과 커뮤니케이션에 적극적인 분
