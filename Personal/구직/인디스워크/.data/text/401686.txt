직무 소개
미리디는 AI 도구를 도입하는 단계를 넘어,
일하는 방식과 조직의 흐름 자체를 재설계
하고 있습니다.
이를 위해 신설된
AXE(AI Transformation Enablement) 스쿼드
는 AI를 안전하고 반복 가능한 방식으로 업무 성과와 조직 생산성에 연결하고, 검증된 프롬프트·자동화·워크플로우를
재사용 가능한 조직 자산
으로 축적합니다.
합류 후에는 AX Manager와 함께 업무 우선순위를 정하고, DevOps팀과 정보보호팀의 검토를 받으며 사내 인프라와 운영 방법을 익힙니다. 익숙해진 뒤에는 반복 업무를 자동화하고, 사내 내부 툴을 더 안전하고 편리하게 배포할 수 있도록 문서와 도구를 개선해 나갑니다.
처음부터 모든 기술을 알고 있거나 인프라 전체를 혼자 책임질 필요는 없습니다. 작은 서비스나 자동화를 직접 만들어 보았거나, 새로운 기술을 찾아 문제를 하나씩 해결해 온 경험이 있다면 이 직무와 잘 맞으실 거예요. 화려한 기술 스택보다는
직접 부딪혀 보고, 필요한 것을 찾아 배우며 조금씩 개선해 나가는 분
을 찾고 있습니다.
|
입사 후 기대 모습
1개월 뒤
Cloudflare·n8n·사내 Agent 서비스의 기본 구조와 운영 절차를 익히고, 기존 런북에서 빠지거나 이해하기 어려운 내용을 보완합니다.
2개월 뒤
정해진 절차에 따라 일상적인 운영 업무를 수행하고, 오류 사례 한 건 이상을 로그로 분석해 해결 과정과 결과를 문서로 남깁니다.
3개월 뒤
반복 운영 업무 한 건을 자동화하거나, 배포 템플릿·알림·운영 문서 가운데 한 가지를 개선해 팀에 공유합니다.
|
주요 업무
“미리디에서 이런 일들을 함께 하고 싶어요”
Cloudflare · n8n 운영
Cloudflare에 배포된 사내 툴과 n8n 워크플로우를 모니터링하고, 로그와 실행 이력을 확인해 이슈의 원인을 파악합니다.
런북에 따라 배포, 워크플로우 재실행, 설정 확인 등 일상적인 운영 업무를 수행하고, 해결하기 어려운 문제는 AX Manager나 DevOps팀과 함께 해결합니다.
반복되는 오류나 불편 사항을 찾아 알림, 스크립트, 설정 등을 개선하며 운영을 자동화합니다.
사내 Agent 서비스 운영·개선 지원
사내 Agent 서비스의 주요 기능을 점검하고, 오류·응답 지연·도구 호출 실패 등의 문제를 재현하고 원인을 파악합니다.
로그와 관측 도구를 활용해 LLM API 호출 상태를 확인하고, 기존 코드와 가이드를 바탕으로 간단한 API·도구 연동을 개발하고 배포합니다.
사용자 피드백과 운영 기록을 바탕으로 개선 과제를 찾고, 테스트와 코드 리뷰를 거쳐 서비스를 개선합니다.
사내 내부 툴 배포 지원
기존 배포 템플릿과 파이프라인을 사용해 사내 내부 툴의 배포를 지원합니다.
체크리스트에 따라 환경변수, 시크릿, 사내 접근 권한이 올바르게 설정되었는지 확인합니다.
배포 과정에서 반복되는 문의와 오류를 수집하고, 문서·템플릿·자동화 스크립트를 개선합니다.
운영 문서화 · 자동화
배포 방법, 자주 발생하는 오류, 해결 절차를 런북과 문서에 지속적으로 반영합니다.
반복되는 수기 작업 가운데 범위가 명확한 업무를 골라 스크립트나 워크플로우로 자동화합니다.
역할과 협업 범위
AX Manager가 업무 우선순위와 서비스 개선 방향을 함께 정합니다.
인프라 구조 변경과 배포 파이프라인의 주요 변경은 DevOps팀과 협업하고, 리뷰를 거쳐 적용합니다.
접근 권한과 보안 기준은 정보보호팀의 기준과 검토 절차에 따라 적용합니다.
미리캔버스 등 고객 대상 프로덕션 서비스의 SLA와 온콜을 담당하지 않습니다.
중요한 인프라·보안 변경이나 장애 대응을 AX Engineer 한 명이 단독으로 판단하고 책임지지 않습니다.
