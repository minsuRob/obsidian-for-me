주요 업무
① 시뮬레이터 코어 개발
칩을 구성하는 하드웨어 유닛(연산 유닛, 메모리, 데이터 이동 경로 등)의 동작을 소프트웨어로 정밀하게 모델링
기준 결과 대비 검증을 통해 실제 하드웨어와의 정합성을 확보하고, 불일치 지점을 분석·수정
신규 칩 세대 출시에 맞춰 시뮬레이터 기능을 확장하고, 다양한 AI 모델의 브링업(bring-up)을 지원
② 성능(사이클 단위) 모델링
기능 검증 중심이던 기존 시뮬레이터에 사이클 단위의 정밀한 성능 예측 기능을 추가
실행 시간 및 지연(latency)을 측정하고, 실제 칩·검증 도구의 결과와 비교해 정확도를 고도화
하드웨어 유닛별 파이프라인 타이밍을 모델링하고, 성능 측정 테스트 스위트를 구축·유지
③ 전력(Power) 모델링
현재 시뮬레이터에 부재한 전력 모델을 처음부터 설계·구축
연산량, 메모리 접근, 데이터 이동 등 활동량 기반의 전력·에너지 소비 추정 모델 개발
성능 대비 전력 효율(energy-efficiency) 분석 체계를 구축하고, 실측 데이터와의 상관성 검증
④ 하드웨어·소프트웨어 팀 협업 지원
하드웨어 설계팀의 칩 동작 디버깅을 위한 레퍼런스로 시뮬레이터 제공
컴파일러·런타임·모델 담당자들이 시뮬레이터 기반으로 개발·테스트할 수 있도록 지원
다양한 AI 모델의 시뮬레이터 상 정상 동작 여부 검증
⑤ 코드 품질 및 테스트
기준 결과 대비 회귀 테스트를 포함한 시뮬레이터 정확성 검증 테스트 작성 및 유지
코드베이스 확장에 따른 구조 개선(리팩터링), 코드 리뷰, CI 유지보수
자격 요건
C++ 실무 역량: 대규모 C++ 코드 베이스의 설계 및 유지보수 경험
컴퓨터 아키텍처 기본기: 프로세서 파이프라인, 메모리 계층, 데이터 이동 등 하드웨어 동작 원리에 대한 이해
정확성에 대한 높은 기준: 하드웨어 동작을 세밀하게 재현하고, 기준 결과 대비 검증하는 꼼꼼함
저수준 디버깅 역량: 미세한 수치·정밀도·경계 조건(edge case) 이슈를 끝까지 추적하는 끈기
협업 문화 적응력: Git 기반 협업 및 코드 리뷰 프로세스에 대한 이해
우대 사항
시뮬레이터/성능 모델링 개발 경험 (아키텍처 시뮬레이터, 사이클 단위 시뮬레이터 등)
전력/에너지 모델링 경험
하드웨어(RTL) 설계에 대한 이해 : 하드웨어 스펙을 소프트웨어 모델로 구현할 수 있는 역량
AI 가속기/NPU 아키텍처 또는 AI 모델 추론 동작에 대한 이해
하드웨어·소프트웨어 협업(HW/SW Co-design) 경험
컴퓨터공학, 전자공학 등 관련 분야 전공자
