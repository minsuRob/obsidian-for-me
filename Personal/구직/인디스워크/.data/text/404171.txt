팀 소개
프로덕트팀은 패스오더 유저와 점주님을 연결하고, 고객의 문제를 집요하게 파고들어 더 나은 경험을 만들어요. 빠르게 학습하고 실행하며, 안정성을 기반으로 혁신과 실질적인 비즈니스 임팩트를 만들어갑니다.
패스오더 Android 앱은 Kotlin 기반의 Native 환경에서 안정성과 성능을 높여왔어요. 이제 AI를 활용해 단순 구현에 드는 시간을 줄이고 본질적인 문제 해결에 집중하는 한편, React Native 브라운필드 전환을 진행하고 있어요.
이를 위해 Android Developer를 모시게 되었어요. Kotlin 기반 앱의 품질과 사용자 경험을 개선하고, AI를 활용한 개발 방식을 발전시키며 서비스 안정성을 지키면서 React Native 브라운필드 아키텍처 전환을 함께 설계하고 실행하는 역할이에요.
이런 경험이 꼭 있어야 해요!
이 포지션에는 Kotlin·Android에 대한 전문성뿐 아니라,
AI 개발 도구를 적극 활용해 생산성을 높인 경험과 React Native·TypeScript로 개발해본 경험이 반드시 필요해요.
Android 실무 역량이 뛰어나더라도 기존 방식에 머물며 AI 기반 개발이나 React Native 전환을 받아들이기 어렵다면 이번 포지션과는 맞지 않아요.
어떤 문제를 AI 개발 도구로 해결했는지, React Native·TypeScript로 무엇을 개발했는지, 그 과정에서 서비스의 안정성과 개발 생산성을 어떻게 높였는지를 중심으로 소개해 주세요.
◈ 서류에서 해당 경험의 보유 여부와 깊이를 확인하기 어려운 경우, 실제 역량이 있더라도 다음 전형으로 이어지지 않을 수 있어요. 서로에게 아쉬운 결과가 생기지 않도록 관련 경험이 명확히 드러나게 작성해 주세요.
이런 업무를 하게 되실 거예요!
○ Android | 안정성과 사용성을 모두 갖춘 앱을 만듭니다
Kotlin·Jetpack Compose 기반으로 패스오더 Android 앱의 안정성과 사용성을 책임집니다. 주문이 집중되는 시간에도 유저가 불편 없이 주문하고 결제할 수 있도록 앱의 안정성과 성능을 지속적으로 개선해요.
○ Brownfield | 기존 앱에 RN을 점진적으로 통합해요
React Native 브라운필드 전환을 위한 기술적 기반을 다져요. 서비스 안정성을 지키면서 기존 Native 앱에 React Native를 점진적으로 통합하고, 기능별 전환 범위와 순서를 설계하며 전환 과정에 참여해요.
○ AI-Driven | 구현은 AI와 함께, 고민은 더 깊게 합니다
Cursor·Claude Code 등 최신 AI 도구를 실무의 핵심 파트너로 활용해 개발 생산성을 높여요. 단순 구현에 드는 시간을 줄이고 설계·아키텍처·비즈니스 로직 고도화에 집중하며, 더 효율적인 AI-Driven 개발 문화를 함께 만들어가요.
○ 아키텍처 | Native와 RN의 경계를 설계합니다
기존 Native 앱과 React Native가 안정적으로 공존할 수 있도록 브릿지와 네이티브 모듈을 설계해요. 두 환경 사이의 데이터 흐름과 인터페이스, 오류 처리 기준을 명확히 정리해 기능이 늘어나도 안정적으로 확장할 수 있는 구조를 만듭니다.
○ 딥다이브 | 경계의 성능 문제까지 파고듭니다
Native와 React Native가 상호작용하는 과정에서 발생하는 JS 스레드 병목과 브릿지 오버헤드, 렌더링 지연 등 성능 이슈의 원인을 분석하고 해결해요.
◈ 이 역할은 대규모 O2O 플랫폼의 아키텍처 설계와 성능 최적화를 직접 경험할 수 있어요. 다양한 직군과 협업하며 기술적 판단을 사용자 경험과 비즈니스 임팩트로 연결하는 역량을 키울 수 있어요.

필요한 정보를 투명하게 공유하고 서로의 강점이 시너지를 내며, 개인과 팀이 함께 더 큰 성과를 만들어요.
《 실력과 성과를 기준으로 확실하게 인정하고 보상해요 》
연차나 직책보다 각자의 포지션에서 만들어낸 결과와 기여를 중요하게 생각합니다.
높은 기준으로 전문성을 발휘하고 만들어낸 성과에 대해 철저한 인정과 확실한 보상으로 보답해요.
《 프로다운 동료들이 모여 한 목표를 향해 달려요 》
역할은 달라도 목표는 같습니다. 자신의 일에 진심인 동료들이 필요한 정보와 인사이트를 나누고
서로의 강점이 시너지를 만들며, 혼자서는 해결하기 어려운 문제에 도전해 더 큰 성과를 만들어요.
《 일을 방해하는 요소와 건강하지 않은 문화와는 타협하지 않아요 》
100% 일에만 몰입할 수 있도록 불필요한 절차와 비효율은 제거합니다. 높은 기준으로 일하되 서로를 존중하며,
일이 아닌 사람 때문에 힘든 조직문화와는 타협하지 않아요.
