## 표시 기준

- **🤖AI직무:** 공고 제목에 AI, LLM, Agent, RAG, ML, FDE, AX 등이 들어 있다. 이 공고들은 각 파일 맨 앞에 모았다.
- **AI언급:** 제목에는 없고 본문에만 AI 관련 단어가 있다.
- **🛠AI도구활용:** 본문에 Claude, Cursor, Copilot, 바이브코딩, AI 코딩, AI 도구·툴, "AI 활용" 같은 표현이 있다. "AI 활용"처럼 넓은 표현도 포함되므로 원문으로 다시 확인할 것.
- **근무지·주요 업무·마감:** 본문 텍스트에서 자동으로 뽑았다.
  - 근무지는 본문에 적힌 경우가 적어서 대부분 `본문에 미기재`로 나온다.
  - 본문이 이미지뿐인 공고는 텍스트를 뽑을 수 없어서 원문 확인으로 표시했다.
  - 마감일을 못 찾으면 태그(`채용시마감`, `상시채용`)를 쓰고, 태그도 없으면 `본문 확인`으로 표시했다.
- 그룹바이처럼 공고를 하나씩 읽고 요약한 것이 아니다. 목록을 자동으로 정리한 것이다.

## 데이터 위치와 갱신 방법

볼트의 숨김 폴더 `Personal/구직/인디스워크/.data/`에 있다. Obsidian 화면에는 보이지 않는다.

- `fetch.py`: API에서 공고를 받아 `raw/`에 저장한다. 요청 사이 3초씩 쉬고, 100건 단위로 약 23번 요청한다.
- `build.py`: `raw/`를 읽어 공고별 본문 `text/<ID>.txt`, 정리 결과 `posts.json`, 두 Markdown 파일을 다시 만든다.
- 다시 받으려면 `.data` 폴더에서 `python3 fetch.py && python3 build.py`를 실행한다.

주요 API 값:

- 태그 ID: 스타트업 `191700265`, IT개발 `191700187`
- 카테고리 ID: 마감/비공개 `191700169`
- 두 태그를 모두 가진 공고만 받으려면 `tags[terms]=…&tags[operator]=AND`를 쓴다.

## 주의

- 인디스워크 robots.txt는 `ClaudeBot`·`anthropic-ai` 같은 AI 학습용 크롤러를 막는다. 이번 수집은 개인 구직용 API 조회라서 천천히 요청했다. 자주, 대량으로 다시 받지는 말 것.
- 마감됐는데도 마감 카테고리로 옮겨지지 않은 오래된 공고가 섞여 있을 수 있다. 지원 전에 원문과 지원 링크를 확인할 것.
