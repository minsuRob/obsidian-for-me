  - 총예산의 **30% 정도만** 한국에서, 나머지는 현지 ATM 인출이 유리
  - 한국에서 USD로 바꿔 대만에서 재환전(이중환전)은 손해

### 통신
- [ ] **eSIM 구매** — 5박 6일이니 **7일권**

- [ ] **타이베이 101 전망대** (Klook/KKday, 89층 / 패스트트랙 옵션)
  - 2026-07-01부터 **매표소·입구가 오피스 빌딩 1층으로 임시 이전** — 현장에서 헤매기 쉬움
  - 운영 11:00–21:00 (입장 마감 20:15)
- [ ] **국립고궁박물원** — 101 **콤보권**이 따로 있음, 묶으면 저렴
- [ ] **마오콩 곤돌라** — 수정 캐빈. 평일 09:00–21:00 / 주말 08:30–22:00
- [ ] **자오시(礁溪) 온천** — 카발란과 같은 이란현. **같은 날 동선으로 묶기**

## 4. 미리 사지 말 것 — 현지에서 하는 게 나음

- **이지카드(悠遊卡)는 대만에서 구매** — 공항·MRT역·편의점에서 즉시 구매/충전. 한국 선구매 이점 없음

## 5. 귀국 전 — 카발란 위스키 반입 ⚠️

> 이번 여행에서 제일 사고 나기 쉬운 지점.

- [ ] **면세 한도: 2병 + 합산 2L + US$400 이하 — 세 조건 동시 충족**
  - 기본 면세(US$800)와 **별도로** 주류에 추가 인정
  - **2인이면 각자 몫으로 총 4병**까지
  - 초과해도 반입 금지는 아님 → 세관 신고 후 납세하면 통관. 미신고 적발이 문제
- [ ] **증류소에서 산 술은 반드시 위탁수하물** — 기내 액체 100ml 규정
  - 기내 반입은 **공항 면세점 구매분만** (밀봉 봉투)
- [ ] 완충재 준비 — 뽁뽁이 또는 옷으로 감싸기, 캐리어 가운데에
- [ ] 위탁 수하물 무게 여유 확인 (700ml 1병 ≈ 1.3kg)
- [ ] **이지카드 잔액 환급** — 편의점 또는 MRT역
