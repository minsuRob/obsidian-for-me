## 3. 결제수단 — 대만에서 뭐로 긁을 것인가

### 결론: 4개를 역할별로 나눠 든다

1. **하나 트래블로그** — 주력 결제. TWD **100% 환율우대(수수료 0%)**
2. **트래블월렛** — ATM 현금 인출 담당. TWD 충전 **0.8%**
3. **현대카드 + 애플페이** — 백업/편의. 대형 가맹점에서만 기대할 것
4. **이지카드 + 현금** — 교통·소액·야시장. **이건 대체 불가**

### 트래블 카드 비교 (대만달러 기준)

| | 하나 트래블로그 | 트래블월렛 |
|---|---|---|
| **TWD 환전 수수료** | **0%** (상시 100% 우대) | **0.8%** |
| 수수료 0% 통화 | 58종 전체 | USD·JPY·EUR **3종뿐** |
| 해외 ATM 인출 | 해외서비스수수료 US$3/건 + 브랜드 1% **면제** | 월 US$2,000 이하 + **제휴 ATM**이면 면제 |
| 인출 한도 | 일 US$6,000 / 월 US$10,000 | ATM당 약 NT$20,000 |
| **애플페이 등록** | ❌ 불가 | ❌ 불가 |
| 실물카드 컨택리스 | ⭕ Visa Touch / Mastercard tap&go | ⭕ |

- **TWD는 트래블로그가 명확히 우위** — 트래블월렛의 0% 혜택은 달러·엔·유로 전용이라 대만에선 안 먹힘
  - 100만원 환전 시 차이 약 **8,000원**. 크진 않지만 굳이 손해 볼 이유 없음
- ⚠️ 트래블로그는 **"외화 하나머니"로 설정**해야 ATM 수수료가 면제됨. 설정 안 하면 원화에서 빠져나가며 수수료 다 붙음

### ATM 인출 — 기계 수수료는 별개

카드사 면제와 **대만 ATM 기계 자체가 떼는 수수료는 다른 얘기**.

- 대만 은행 ATM 고정 수수료 **NT$100~150 (약 4,400~6,500원)** — 한 번 뽑을 때마다
- **국태세화은행(國泰世華 / Cathay United)** = 트래블월렛 제휴 → **기계 수수료 무료**
  - **초록색 나무 로고**, **패밀리마트 안**에 많음
- 대응: **횟수를 줄여 한 번에 크게 뽑기**. 1회 한도 약 NT$20,000(약 87만원)
- 출금은 보통 **NT$1,000권**으로 나옴 → 야시장 쓰려면 편의점에서 잔돈으로 깨기

### 애플페이 — 기대치를 낮춰야 함

**한국 쪽 (2026-08 현재)**

- 애플 지갑에 넣을 수 있는 한국 카드는 **사실상 현대카드뿐** (신용·일부 체크)
- KB국민카드: 2026년 5월 Visa 등록 정황은 있으나 **정식 출시 확정 아님**
- 신한카드: 2026년 3월 도입 **중단**
- **트래블월렛·트래블로그는 애플페이 등록 불가** → 대신 **실물 카드를 단말기에 태그**(Visa Touch)

**대만 쪽 — "된다"와 "안 된다"가 둘 다 사실**

| | 상태 |
|---|---|
| 까르푸·RT마트·코스트코, 백화점, 딘타이펑급 체인 | ⭕ 대체로 됨 |
| **편의점(패밀리마트·세븐일레븐)** | ⚠️ **한국 발행 카드 거절 사례 다수** |
| **MRT·시내버스** | ❌ 불가 — 이지카드 필수 |
| 야시장·노점·로컬 식당 | ❌ 현금 |

- 대만 자체는 애플페이 보급률이 높지만, 그건 **대만 발행 카드 기준**. 한국·일본 발행 카드는 단말기가 거절하는 경우가 잦음 (현지 점원이 "한국·일본 카드는 잘 안 된다"고 안내한 사례 보고)
- **수수료도 불리**: 현대카드 해외 이용은 국제브랜드 1~1.1% + 해외이용수수료 0.18~0.2% ≈ **약 1.2%**. 트래블로그 0%와 비교하면 편의성 값
- **결론: 애플페이는 메인 아님. 백업으로만.**

### 출국 전 결제 관련 체크

- [ ] **하나 트래블로그 발급** + TWD 충전 + **"외화 하나머니" 설정 확인** ← 이거 안 하면 수수료 면제 안 됨
- [ ] **트래블월렛 발급** (ATM 인출 백업용, 소액만 충전해도 됨)
- [ ] 현대카드 보유 시 **애플페이(지갑 앱) 등록** — 한국에서 미리
- [ ] 모든 카드 **해외결제 차단 해제** 확인

## 6. 귀국 전 — 카발란 위스키 반입 ⚠️

> 이번 여행에서 제일 사고 나기 쉬운 지점.

- [ ] **면세 한도: 2병 + 합산 2L + US$400 이하 — 세 조건 동시 충족**
  - 기본 면세(US$800)와 **별도로** 주류에 추가 인정
  - **2인이면 각자 몫으로 총 4병**까지
  - US$400 ≈ **약 55만원** / ≈ NT$12,000 — 카발란 상위 라인은 1병에 이 한도를 훅 먹으니 **가격 합산 주의**
  - 초과해도 반입 금지는 아님 → 세관 신고 후 납세하면 통관. 미신고 적발이 문제
- [ ] **증류소에서 산 술은 반드시 위탁수하물** — 기내 액체 100ml 규정
  - 기내 반입은 **공항 면세점 구매분만** (밀봉 봉투)
- [ ] 완충재 준비 — 뽁뽁이 또는 옷으로 감싸기, 캐리어 가운데에
- [ ] 위탁 수하물 무게 여유 확인 (700ml 1병 ≈ 1.3kg)
- [ ] **이지카드 잔액 환급** — 편의점 또는 MRT역 (**카드값 NT$100은 환급 안 됨**)
