## 핵심 인용 (원문)
> 기술 전문성은 "이전보다 더 큰 배율기(multiplier)"가 된다

## 요약 (한국어)
- **소프트웨어 진화 3단계**: 1.0 명시적 코드 / 2.0 데이터 기반 신경망 / 3.0 자연어 프롬프트로 AI 실행.
- **두 핵심 개념**:
  - **검증가능성(Verifiability)**: 결과 검증이 쉬울수록 자동화에 적합.
  - **들쭉날쭉한 지능(Jagged Intelligence)**: LLM은 영역별로 성능이 불균형 → 인간 감독이 필요한 이유.
- **성장 전략**: ① 검증 가능한 작업부터 에이전트에 위임하며 감독 능력 강화 ② 토큰 처리량 극대화로 병렬 사고 학습 ③ Software 3.0 관점으로 기존 솔루션 재검토.
- 전문성은 사라지는 게 아니라 더 큰 배율기가 됨. 에이전트 감독에는 깊은 이해가 필수.
