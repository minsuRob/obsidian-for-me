# MAKi MCP 메시지 포맷

MAKi MCP로 보낼 때 같은 내용이라도 **메시지 텍스트의 구조**에 따라 화면 렌더링이 달라진다. 이 페이지는 Cursor 전송본과 Codex 전송본의 차이를 정리한 메모다.

## 관찰
- Cursor 전송본은 `제목 + 번호 목록 + 하위 bullet` 구조가 잘 유지돼서, 화면에서 카드형으로 더 읽기 쉽게 보였다.
- Codex 전송본은 `public_create_message_text`로 보낸 plain text라, 줄바꿈은 있었지만 목록 계층이 상대적으로 덜 살아났다.
- 내용 자체보다 **전송 시 텍스트 구조**가 표시 품질에 큰 영향을 줬다.

## 권장
- 일일정리나 요약을 보낼 때는 먼저 제목을 한 줄로 두고, 그 아래에 번호 목록을 둔다.
- 각 번호 아래에는 핵심 bullet만 짧게 둔다.
- 문구가 길어질수록 하위 bullet으로 분리한다.

## 예시 포맷
```text
2026-07-03 오늘 일감 정리
1. 최우선: 모바일 컴포저 멘션
   - 사람 언급은 native
   - todo/note 일감 언급 추가
2. 최우선: 웹 assign 일감 언급
   - /assign 슬래시 커맨드
   - Lexical 기반
3. 중간: Mac 빌드 워크트리 유일성 검증
   - frontend validate 공유 워크트리 경쟁 확인
```
